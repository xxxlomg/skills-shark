使用手册 · v0.2.1

从乱到顺，
十分钟上手 SkillsShark

本手册覆盖安装、扫描、翻译、管理（Hub 引用台账）、打包分享与创作。所有数据默认存于本地，免登录即可使用。

简介

SkillsShark（技能鲨）是一款本地桌面工具，用于统一管理、翻译与打包散落在 QwenPaw、Cursor、Claude Code 等各 AI 工具里的 Agent Skills。

「鲨」取敏锐、精准、快之意。它的目标只有一句话：让中文用户一眼看懂、一用就会别人的技能，并把自己的技能干净地发出去。

当前版本 v0.2.1（开发中），提供 Windows x64 NSIS 安装包。

安装与启动

从发布页下载 .exe 安装包，双击按向导安装即可。安装界面支持简体中文 / English，可选择「仅为我安装」或「所有用户」，并内嵌 WebView2 引导。

首次启动会在系统数据目录 %AppData%\Skills Shark 创建配置与数据；若发现旧版目录，会自动迁移并自校验，不会丢数据。

扫描你的技能

SkillsShark 不内置技能——它把你各工具里的 skills 目录「扫」进来统一管理。

配置扫描路径

在「设置 → 扫描路径」中添加目录，例如：

  • ~/.qwenpaw/skills
  • ~/.cursor/skills
  • ~/.claude/skills

每个路径可设显示名（标签）与启用开关，按标签分组展示。源目录被删除时，对应技能会自动标记为失效，不会再误点进详情。

自动检测

点击「自动检测」，应用会扫描磁盘上常见 AI 工具的默认 skills 目录，列出存在但尚未配置的路径，一键加入即可。

翻译技能

英文 SKILL.md 看不懂？让 LLM 流式生成中英对照译文。

配置 LLM

在「设置 → LLM」填入 API Key / Base URL / 模型（OpenAI 兼容接口）。密钥仅存本地、脱敏显示。填好后可用「测试连接」按钮（max_tokens 5，15 秒超时）验证配置是否正确。

流式翻译

打开技能详情抽屉，点「翻译」即开始。译文边生成边显示，大文件自动按 2000 字符分块，并有 30 秒空闲超时保护。翻译完成自动持久化，并派生中文标题与描述。

增量跳过

翻译前计算原文 SHA-256 哈希，与已存译文比对；原文未变则直接跳过，重复打开不再等待。修改了原文才会重新翻译。

管理技能

浏览与搜索

首页按扫描标签分组展示分类卡，进入分类看技能列表，点开即右侧详情抽屉——三级导航清晰。支持网格 / 列表双布局；随时按 Ctrl+K 调出全局搜索，中文名、原名、描述全字段命中。

引用台账 Hub

技能要落到具体 AI 工具才能用。Hub 统一管理技能与各工具之间的链接（junction）/ 副本关系：

  • 出处 → 落点可视化：技能来自哪、装到哪个工具，一图看清；
  • 健康色条：左缘状态条正常时隐藏，异常才上色提示；
  • 卡片菜单：转副本 / 重建 / 解除，异常时才露出「重建」主按钮；
  • 多维筛选：按类型 / 状态 / 落点工具勾选，已选条件可内联点 × 移除。

打包与分享

把喜欢的技能打包成 .skillpack，发给同事或社区，对方即装即用。

创建 Pack

在 Packs 页「新建 Pack」，填名称 / 版本（默认 1.0.0）/ 作者，从全部技能中勾选（单次上限 40 个；源文件已失效的技能不可选）。应用会生成 pack.json 元数据、GitHub 可直接渲染的 README.md，并随包写入 i18n/ 双语译文 sidecar。

导入 Pack

点「导入 .skillpack」虚线卡，或直接把 .skillpack / .zip 拖进窗口。应用探测压缩包内是否含 pack.json：是则展示包名 / 版本 / 技能数；否则按普通 zip 技能库导入。

当前版本不支持从 URL 直接安装 Pack，需向分享者索取文件后本地导入。

安装到技能库

导入只是进入 Packs 库，技能尚未落地。对目标包点「安装」：包内每个技能目录拷入 imported/<包名>/，写入 .import.json 记录来源，技能随即出现在「导入」分类下。

三道安全闸

  • 版本闸：包的 format_version 高于当前应用版本时拒绝导入，提示先升级；
  • sha256 自验：清单登记的每个文件逐一校验哈希，任一不符即整包拒收；
  • 不覆盖：与已有包 id 冲突时自动改名（如 my-pack-2）。

「删除」仅移除包本体，不影响已安装到技能库的副本，也不影响已在 Hub 建立的引用。

创作技能

从「看别人的」到「做自己的」——v0.2 起，你可以自己写技能。

创作工作台

全页沉浸式编辑：新建 / 编辑 skill，name 前置 + 「做什么 / 何时用」引导表单自动派生 description；Markdown 编辑 / 分栏 / 预览三视图；附带资源文件树（新建 / 删除 / 查看，SKILL.md 受保护）；改名时目录与 frontmatter 同步。

草稿自动保存、三态恢复，Ctrl+S 即存，离开有返回守卫，安心写。

AI 创作

模型直出 SKILL.md 原文流式生成，右侧预览实时滚动跟随，可「应用到正文」。60 秒无输入会淡入引导；内容参考以只读卡分组展示，不污染正文。

数据目录

运行时数据与代码分离，统一位于系统数据目录（Windows：%AppData%\Skills Shark）：

Skills Shark/
├── config.json          # 扫描路径 / LLM 配置（仅存本地）
├── translations.json    # 译文索引
├── translations/        # 中英对照译文文件
├── packs/               # 已创建的 Skill Packs
└── imported/            # 由 zip / URL / Pack 安装进来的技能库

重装应用或换机器，只要备份这个目录，数据与译文都在。首次启动若发现旧版目录会自动迁移并自校验。

常见问题

能从链接 / URL 直接安装 Pack 吗？

当前版本（v0.2.1）不支持从 URL 直接安装。需向分享者索取 .skillpack 文件后本地导入。从 Git 仓库货架导入在后续规划中。

删除 Pack 会影响已安装的副本吗？

不会。「删除」只移除 packs/<id> 的包本体；已「安装」到技能库的副本是独立物理拷贝，Hub 引用也不受影响。

支持 macOS / Linux 吗？

v0.2.1 主线为 Windows x64。Tauri 2 支持跨平台打包（.dmg / .AppImage），其他平台的官方构建以发布页为准。
