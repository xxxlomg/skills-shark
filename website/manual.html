快速上手

SkillShark（技能鲨）是一款本地优先的 AI 技能管理桌面应用。它把散落在各个 AI 工具里的技能扫描出来、翻译成中文、统一管理、跨工具引用，还支持创作自己的技能并打包分享。

本章用三步带你走通「扫描，读懂」的最短路径。

第一步：配置模型 Key

翻译与 AI 创作需要一个模型 Key。打开右上角「设置」，进入「LLM 配置」：

  1. 填入模型服务的 Base URL、API Key 与模型名；
  2. 点击「测试连通性」，等待真实连通结果；
  3. 保存。Key 只写入本机数据目录（Windows 为 %APPDATA%\Skills Shark），绝不进入任何业务数据流。

Key 由你自备，应用本身不提供模型额度。你可以随时在设置中切换服务商或关闭配置。

第二步：同步扫描技能

点击右上角「同步」。SkillShark 会按设置中的扫描路径遍历各工具的 skills 目录，读取每个 SKILL.md 的元数据，按工具分组展示为卡片。

两点说明：

  • 在「设置 → 工具」中停用的工具不会参与扫描；
  • 多个工具共用同一源目录时，首页只保留一张代表卡，全部安装位置记录在详情抽屉的「安装位置」区。

第三步：翻译第一个技能

点击任意技能卡片打开详情抽屉，点「AI 翻译」按钮：

  • 翻译过程流式输出，中英对照实时呈现，可随时停止；
  • 译文包含中文标题、中文描述与全文翻译，保存后卡片直接显示中文标题；
  • 原文更新导致译文过期时，详情页会提示，可一键重翻；
  • 不再需要时，可在详情页删除译文回到原文。

完成这三步后，建议继续阅读「功能详解」中的 Hub、Skill Packs 与创作章节，把技能真正用起来。

功能详解

技能库

技能库是首页，展示所有被扫描到的技能，按来源工具分组为合集卡片。

  • 卡片上的徽标表示该技能被哪些工具引用（来自 Hub 台账）；
  • 顶部统计栏显示技能总数、已翻译数、译文丢失数与 Pack 数量；
  • 右上角可切换网格 / 列表布局，偏好会记住；
  • Ctrl/Cmd + K 打开命令搜索，可直达任意技能、合集、工具，或快速发起导入、建链、打包等操作。

进入某个合集后，可对单个技能发起翻译、查看详情、建立 Hub 引用。

AI 翻译

翻译是本产品的核心能力，解决「技能是英文的，读不懂、不知道怎么用」的问题。

  • 流式输出：译文逐段出现，不必等全文完成；翻译中可随时停止；
  • 中英对照：译文与原文分栏呈现，方便核对；
  • 增量机制：以原文内容哈希判断是否需要重翻，原文没变则跳过，不浪费 token；
  • 批量翻译：合集页可一键批量翻译该合集下所有技能；
  • 元数据同译：frontmatter 中的标题与描述也会翻译，卡片与搜索结果直接显示中文；
  • 过期提醒：原文更新后译文标记为过期，可一键重翻；
  • 存储位置：所有译文统一存放在数据目录的 translations/ 下（Windows 为 %APPDATA%\Skills Shark\translations\），文件名为技能 ID 的 percent-encode，元数据索引记在 translations.json，不侵入任何工具目录；
  • 删除译文：详情页提供删除入口，删除后卡片回到原文显示。

Hub：跨工具引用

很多技能只存在于某一个工具的目录里，其他工具用不到。Hub 通过引用把技能「跨」过去：

  • 新建引用：选择技能、目标工具、方式（Windows 上三种都可用，其他平台用复制或移动）：
    • 链接（junction）：不占额外空间，源目录更新自动同步，推荐；
    • 复制：独立副本，互不影响；
    • 移动：源目录的技能会移到目标工具（谨慎使用）。
  • 台账管理：所有引用登记在案，可查看来源、目标、方式与时间；
  • 断链检测：源被删或 junction 失效时自动标记为断链，并提供修复（重建）入口；
  • 反向引用：在技能详情页可以看到「这个技能被引用到了哪些工具」，也可以从这里直接发起新引用；
  • 引用分组：台账按源目录分组展示，一眼看清每个来源的分发情况。

创作工作台

不会写技能？工作台把创作过程拆成了可视化的步骤：

  • 草稿目录：创作中的技能保存在独立草稿目录，与已扫描的技能隔离；
  • 文件树：技能的每个文件都可新建、编辑、删除；
  • 双栏编辑：左侧 SKILL.md 编辑器（Ctrl/Cmd + S 保存），右侧实时校验面板；
  • 改名同步：重命名目录时，frontmatter 中的 name 字段自动同步修改；
  • 生成 SKILL.md：已有 openai.yaml 的技能可一键生成规范的 SKILL.md；
  • AI 创作：配置 Key 后，描述你的想法，AI 流式直出 SKILL.md，可随时停止；
  • 校验器：按 Claude / Codex 两套官方规则做结构校验，给出具体修改提示（命名须 hyphen-case、描述须「做什么。当何时用时。」等）。

Skill Packs

Pack 是技能的打包分发单元：

  • 创建：勾选若干技能（可只选未翻译版本或带译文版本），填名称与描述即可打包；带译文打包时，译文一并进入包内，导入方无需重新翻译；
  • 导入：支持拖拽 .skillpack / .zip 到窗口任意位置，或从 Packs 页选择文件；
  • 安装：把 Pack 内的技能安装到「导入」库，随即可翻译、引用；
  • 导出：把已创建的 Pack 导出为 .skillpack 文件，发给任何人；
  • 发布：配置「技能仓库」后，可一键把 Pack 推送到你自己的 git 仓库货架（见下文）。

所有 Pack 文件统一存放在数据目录的 packs/ 下，安装校验采用三道闸：pack.json 白名单、全文件 sha256 校验、SKILL.md 解析，任何一闸失败即整体拒绝。

导入

除 Pack 外还支持三种导入方式：

  • 本地 zip：拖拽或选择 zip 文件，后端自动识别是普通 zip 还是 Skill Pack；
  • URL 直导：粘贴技能 zip 的下载链接；
  • Git 货架：输入 git 仓库地址，浏览其中的 Pack 并按提交选择性导入。

下载文件统一放在设置的「下载路径」（默认为数据目录的 imported/）。

Git 货架与发布

SkillShark 把 git 仓库当作技能货架：

  • 发布侧：在「设置 → 技能仓库」配置本地仓库路径与远端 URL 后，Pack 卡片上出现「发布」按钮。发布会把 Pack 文件与 index.json 索引一起提交并推送；远端有新提交时自动 rebase 重试。发布前会检查：系统 git 可用、仓库已配置、工作区干净；
  • 导入侧：Packs 页「从 Git 导入」可浏览任意符合结构的货架仓库，选择 Pack 与提交导入。

凭据走你本机自己的 git 配置，SkillShark 不接触你的账号密码。

设置说明

设置页分四个区：

  • LLM 配置：Base URL、API Key、模型名与连通性测试。保存前可先测试，连通失败会给出具体网络错误提示；
  • 工具：管理被扫描的工具（启用 / 停用 / 新增自定义工具）、下载路径。删除仍有引用的工具会先拦截并提示；
  • 技能仓库：发布用的本地仓库路径与远端 URL；
  • 外观：浅色 / 深色主题，四种强调色可选。

常见问题

译文状态显示「丢失」是什么意思？

原文被移动或删除后，译文找不到对应源文件，就会标记为「丢失」。丢失的译文不会被删除，源文件恢复或重新扫描到之后，对应译文会自动找回。

为什么翻译 / AI 创作按钮点不了？

通常是 Key 未配置或配置无效。打开「设置 → LLM 配置」完成配置并测试连通性。如果连通性测试失败，留意提示中的具体网络错误（代理、证书、域名解析等）。

Mock 模式是什么？怎么开？

Mock 模式用模拟数据运行整个界面，用于无后端环境的预览与开发。在地址栏加 ?mock=1 参数即可启用（如 http://localhost:5173/?mock=1）。打包后的桌面应用内置真实后端，无需关心。

Pack 卡片的「发布」按钮为什么是灰的？

按顺序检查：

  1. 系统是否安装了 git（设置保存或重启应用后会重新检测）；
  2. 「设置 → 技能仓库」是否配置了本地仓库路径与远端 URL；
  3. 配置的仓库路径是否真实存在且已完成初始化；
  4. 仓库工作区是否干净（有未提交改动时不允许发布）。

按钮悬停时会直接显示具体原因。

junction 链接是什么？其他平台能用吗？

junction 是 Windows 的目录连接机制，目标目录直接指向源目录：不占额外空间，源更新后目标自动同步。其他平台请改用「复制」或「移动」方式建链。

删除 Pack 会影响已安装的技能吗？

不会。删除 Pack 只移除 Packs 库中的打包记录，已经安装到「导入」库的技能、已导出的 .skillpack 文件都不受影响。

我的数据安全吗？

SkillShark 是本地优先设计：

  • 配置与 Key 只存放在本机数据目录（Windows 为 %APPDATA%\Skills Shark）；
  • 除你主动配置的模型服务与 git 远端外，不产生任何网络请求；
  • 翻译、打包、引用等操作全部在本机完成。

应用的数据都存放在哪里？

统一在数据目录下（Windows 为 %APPDATA%\Skills Shark，即 C:\Users\你的用户名\AppData\Roaming\Skills Shark；也可用环境变量 SKILLS_SHARK_DATA 整体改址）：

  • config.json：应用配置（含 Key）；
  • translations/ 与 translations.json：全部译文；
  • packs/：Pack 文件；
  • imported/：Pack 安装出的技能，也是下载导入的默认位置（可在设置改路径）；
  • authored/：创作工作台的草稿；
  • links.json：Hub 引用台账；
  • tmp/：git 货架克隆临时区，启动自动清理；
  • debug.log：调试日志。

备份该目录即可完整迁移你的所有数据。
