01

设计原则

什么是「瑞士国际主义」——不是风格，是纪律。

A

网格统治一切

所有对齐基于 8pt 网格，视觉层级由网格密度而非装饰决定。

B

发丝线代替阴影

用 hairline 描边定义边界，不用投影制造「悬浮感」。深度来自叠放与留白。

C

单一强调色

全界面只保留一个强调色（珊瑚橙），其余均为中性灰阶。克制即力量。

D

左对齐 + 大留白

文本左对齐，区块间留足呼吸空间。信息密度由留白控制。

E

克制动效

动效只用于反馈状态（hover/过渡），时长 ≤200ms，无漂浮、无光晕。

F

无衬线 + 数字系统

全无衬线字体，编号/数据用等宽字，营造工具感与秩序感。

02

暖中性色为主，珊瑚橙为唯一强调。适配深/浅双主题。

03

06

应用到 v0.2.2 UI 重写

从毛玻璃到瑞士风 —— 迁移映射表。

移除 → 替换

  • glass / backdrop-blur → 纯色 surface + hairline 边框
  • drift 光晕 / blob → 纯色背景 + 极淡网格线
  • card-glow / 辉光阴影 → 无阴影，hover 描边加深
  • bg-gradient 渐变按钮 → 纯强调色填充
  • rounded-[18px] / 药丸 → 6–8px 微圆角
  • 4× accent 预设 → 收敛为单一珊瑚橙
  • hover 上浮 translateY → 仅 border-color 变化

保留

  • 系统字体栈（零加载，保留）
  • 深/浅双主题切换（next-themes）
  • 8pt 对齐节奏
  • 等宽字体用于编号/数据
