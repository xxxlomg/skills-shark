技能鲨，替你盯着所有技能。

五步，把技能用起来

从「看不懂」到「传出去」，每一步都在本机完成。

  1. 读懂它

    英文技能流式翻译成中英对照，连标题和描述一起译。

  2. 管起来

    扫描所有工具的 skills 目录，分组、搜索、看清每个技能装在哪。

  3. 跨过去

    用 junction 把技能引用到其他工具，不占空间，源更新自动同步。

  4. 写一个

    创作工作台加 AI 直出 SKILL.md，Claude 与 Codex 双生态规则实时校验。

  5. 传出去

    打包成 .skillpack 发给任何人，或一键发布到你的 git 货架。

为技能而生的工具箱

流式翻译

中英对照实时呈现，增量重翻不浪费 token，随时可停。译文过期自动提醒，一键重翻。

多源扫描

内置主流 AI 工具来源，也能自定义路径，一次同步全部入库。

Hub 引用

junction、复制、移动三种方式，台账登记，断链自动检测与修复。

创作工作台

文件树、双栏编辑、改名同步、AI 流式创作。校验器盯着每个字段，命名、描述不合规立刻告诉你怎么改。

Skill Packs

勾选打包，带译文分发。三道闸校验，导入即还原。

Git 货架

仓库即货架。浏览导入别人的 Pack，也把自己的发布出去，凭据走你自己的 git 配置。
