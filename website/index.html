01—08

八项能力，覆盖技能的整个生命周期

从把别人的技能看明白，到把自己做的技能发出去——都在一个本地应用里完成。

01

多源扫描

配置多个 skills 目录（路径 / 标签 / 启用开关），按标签分组展示；源目录删了自动标记，不再误点。

02

流式翻译

调 LLM 流式生成中英对照，大文件自动分块；哈希增量跳过未变化原文，并自动派生中文标题与描述。

03

浏览视图

分类卡 → 分类详情 → 详情抽屉三级导航，网格 / 列表双布局；Ctrl+K 全局搜索，中英文全字段命中。

04

引用台账 Hub

技能与 AI 工具之间的链接 / 副本统一管理，出处 → 落点可视化，左缘健康色条让状态一目了然。

05

Skill Packs

勾选技能打包成 .skillpack，导入 / 导出 / 安装；sha256 逐文件自验，版本闸防错，同名自动改名。

06

导入管线

支持本地 zip 与 Git URL 两种来源，安全解压预览；提交时拍平嵌套，同名文件自动改名，不覆盖已有。

07

创作工作台

全页沉浸式写技能，AI 直出 SKILL.md 原文，分栏实时预览；草稿自动保存、三态恢复，Ctrl+S 即存。

08

统一 AI 层

翻译 / AI 创作 / 连接测试共用一套 LLM 配置；各模块 prompt 模板集中在一处管理，维护省心。

五个动作，从乱到顺

不需要先把所有工具研究透。打开应用，按这个顺序走一遍就够了。

01

扫描

指向各 AI 工具的 skills 目录，一次收进统一列表。

03

分类、搜索、引用台账，技能流向哪个工具一清二楚。

04

WHY

为什么是本地优先

技能是你的资产。它们不该被锁在某个云端账号，也不该离开你的电脑。

中英对照

流式翻译，边出边看

原文进、译文出，进度条实时跟随。大文件自动分块，已翻译的原文靠哈希增量跳过，重复打开不再等。

秒搜

Ctrl+K 全局搜索

中文名、原名、描述全字段命中，无论技能来自哪个工具，一次搜到。

安全分发

.skillpack 自验

版本闸拒绝不兼容的包，sha256 逐文件校验，导入不覆盖已有——分享放心，安装安心。

隐私

数据不离开你的电脑

配置、译文、Packs、导入库统一存放在系统数据目录，重装不丢；LLM 密钥只存本地、脱敏显示。免登录，即装即用。

DATA

运行时数据，与代码分离

所有个人数据放在系统数据目录，不在应用安装目录里。重装系统或迁移应用，数据都在；首次启动还会自动迁移旧目录并自校验。

你随时可以打开这个目录，手动备份或查看——一切透明。

%AppData%\Skills Shark

  config.json # 扫描路径 / LLM 配置
