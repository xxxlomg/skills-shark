五步，把技能用起来

从「看不懂」到「传出去」，每一步都在本机完成。

01

读懂它

英文技能流式翻译成中英对照，标题、描述、正文一起译，可随时停止。

02

管起来

扫描所有工具的 skills 目录，按工具分组、搜索，看清每个技能装在哪。

03

跨过去

用 junction 把技能引用到其他工具，不占空间，源更新自动同步。

04

写一个

创作工作台加 AI 直出 SKILL.md，Claude 与 Codex 双生态规则实时校验。

05

传出去

打包成 .skillpack 发给任何人，或一键发布到你的 git 仓库货架。

为技能而生的工具箱

翻译、引用、创作、分发，四个环节都有对应的工具。

CORE

流式翻译

中英对照实时呈现，增量重翻不浪费 token，译文过期自动提醒、一键重翻。元数据同译，卡片与搜索结果直接显示中文标题。

SCAN

多源扫描

内置主流 AI 工具来源，也能自定义路径，一次同步全部入库，自动去重归档。

HUB

引用台账

junction、复制、移动三种方式，台账登记、反向引用、断链自动检测与修复。

AUTHOR

创作工作台

文件树、双栏编辑、改名同步、AI 流式创作。校验器盯着每个字段，命名、描述不合规立刻告诉你怎么改。

PACK

Skill Packs

勾选打包，带译文分发。三道闸校验，导入即还原。

GIT

Git 货架

仓库即货架。浏览导入别人的 Pack，也把自己的发布出去，凭据走你自己的 git 配置。

你的 Key、你的技能、你的数据，
都留在本机。

SkillsShark 是本地优先设计。除你主动配置的模型服务与 git 远端，不产生任何网络请求。

  • 配置与 Key只写在本机数据目录，绝不进入业务数据流。
  • 操作全本地翻译、打包、引用全部在本机完成。
  • 一键迁移备份一个数据目录，完整带走所有数据。

数据放在哪，一目了然

所有数据统一存放在本机数据目录，Windows 下为 %APPDATA%\Skills Shark（可用 SKILLS_SHARK_DATA 整体改址）。

  • 译文与翻译索引统一存放，不侵入任何工具目录
  • Pack、引用台账、草稿各自独立，结构清晰
  • git 货架克隆临时区自动清理
