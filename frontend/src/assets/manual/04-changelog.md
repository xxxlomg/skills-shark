# 版本更新记录

## v0.2.1（当前版本）

- 使用手册从功能 Tab 移至右上角「关于」菜单，升级为白皮书形态：左侧目录 + 正文分章，新增版本更新记录；
- 新增产品官网首版。

## v0.2.0

枢纽化与创作套件，让 SkillShark 不止于「看」：

- Hub：跨工具引用层，junction / 复制 / 移动三种方式，台账登记、断链检测与修复、反向引用、按源分组；
- 创作工作台：草稿、文件树、双栏编辑、改名同步、SKILL.md 生成、AI 流式创作；
- 校验器：Claude / Codex 双生态规则校验，结构化问题与修改提示；
- Git 货架：从 git 仓库浏览导入 Pack，也可把本地 Pack 一键发布到你的 git 仓库；
- 工具注册表：多工具扫描来源统一管理，支持自定义工具；
- Pack 带译文闭环：打包可携带译文，导入即还原；
- 命令搜索（`Ctrl/Cmd + K`）、手册页、外观四色、AI 翻译可终止等体验改进。

## v0.1.0

首发版本，核心能力：

- 多工具 skills 目录扫描与分组展示；
- AI 流式翻译，中英对照，元数据同译，增量重翻；
- Skill Pack 创建 / 导入 / 导出 / 安装；
- zip 与 URL 两种导入方式；
- 深色 / 浅色双主题，玻璃拟态界面。
